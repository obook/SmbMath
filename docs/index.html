Extension LibreOffice Writer

Les formules de maths, sans quitter le clavier.

SmbMath ajoute à Writer un menu et une barre d'outils pour insérer des formules mathématiques prêtes à compléter, puis harmoniser d'un seul geste la police et la taille de toutes les formules d'un document. Conçu par un enseignant, pour préparer sujets, corrigés et fiches d'élèves.

I.Un menu, cinq outils

Insérer Formule
Transforme le texte sélectionné en formule, ou ouvre l'éditeur de formules si aucun texte n'est sélectionné.
Formulaire
Dix-sept formules prédéfinies, classées par ordre alphabétique, prêtes à compléter.
Synchroniser
Applique une police, une taille et des réglages uniformes à toutes les formules du document.
Options
Choix du mode d'insertion : texte brut ou objet OLE.
À propos
Auteur et numéro de version de l'extension.

III.Des formules toutes identiques

Un document rassemble vite des dizaines de formules aux réglages disparates. L'outil Synchroniser parcourt toutes les formules OLE du document et leur applique les mêmes réglages :

PoliceCMU Serif
Taille de police12 pt
Exposants et indices65 %
Limites65 %

La police CMU Serif (Computer Modern) est celle de LaTeX ; c'est elle qui compose les titres et les formules de cette page. Installée sur votre machine, elle donne aux documents Writer le rendu d'un ouvrage de mathématiques.

IV.Installation

  1. Télécharger smbmath.oxt La dernière version publiée sur le dépôt GitHub.
  2. Ouvrir le gestionnaire des extensions Dans LibreOffice Writer : menu Outils > Gestionnaire des extensions.
  3. Ajouter le fichier Cliquer sur Ajouter, sélectionner smbmath.oxt et accepter la licence.
  4. Redémarrer LibreOffice Le menu SmbMath apparaît dans la barre de menus de Writer. Les mises à jour seront ensuite proposées automatiquement.

Extension expérimentale : conservez une copie de vos documents avant de l'utiliser. Le créateur ne peut être tenu responsable de la perte de données.

V.Depuis les sources

Le paquet .oxt est une archive ZIP du dossier src/ : lancer ./make_extension.sh (Linux) ou make_extension.bat (Windows). Le code est écrit en StarBasic, dans deux modules : MainModule.xba (insertion des formules, options) et SyncModule.xba (synchronisation).
