SmbMath

Extension pour LibreOffice Writer

❦

Un menu et une barre d'outils pour insérer des formules mathématiques prêtes à compléter, puis harmoniser d'un seul geste la police et la taille de toutes les formules d'un document. Conçu par un enseignant, pour préparer sujets, corrigés et fiches d'élèves.

Télécharger Code source

Version 2.0, pour Windows et Linux

Extension expérimentale : conservez une copie de vos documents avant de l'utiliser. Le créateur ne peut être tenu responsable de la perte de données.

IUn menu, cinq outils

Insérer Formule
Transforme le texte sélectionné en formule, ou ouvre l'éditeur de formules si aucun texte n'est sélectionné.
Formulaire
Dix-sept formules prédéfinies, classées par ordre alphabétique, prêtes à compléter.
Synchroniser
Applique une police, une taille et des réglages uniformes à toutes les formules du document.
Options
Choix du mode d'insertion : texte brut ou objet OLE.
À propos
Auteur et numéro de version de l'extension.

IIISynchronisation

Un document rassemble vite des dizaines de formules aux réglages disparates. L'outil Synchroniser parcourt toutes les formules OLE du document et leur applique les mêmes réglages :

PoliceCMU Serif
Taille de police12 pt
Exposants et indices65 %
Limites65 %

La police CMU Serif (Computer Modern) est celle de LaTeX ; c'est elle qui compose les formules de cette page. Installée sur votre machine, elle donne aux documents Writer le rendu d'un ouvrage de mathématiques.

IVInstallation

  1. Télécharger smbmath.oxt, la dernière version publiée sur le dépôt.
  2. Dans LibreOffice Writer : menu Outils, Gestionnaire des extensions.
  3. Ajouter le fichier smbmath.oxt et accepter la licence.
  4. Redémarrer LibreOffice : le menu SmbMath apparaît dans Writer.

Les mises à jour publiées sur le dépôt sont ensuite proposées automatiquement par le gestionnaire des extensions.

VDepuis les sources

Le paquet .oxt est une archive ZIP du dossier src/ : lancer ./make_extension.sh (Linux) ou make_extension.bat (Windows). Le code est écrit en StarBasic, dans deux modules : MainModule.xba pour l'insertion des formules et les options, SyncModule.xba pour la synchronisation.
